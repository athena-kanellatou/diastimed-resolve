## Order of work with people

1. Send the bounded review pack only after Athina authorizes contact, or let her share it herself.
2. Record the reviewer's actual role and scope; implement justified changes and document disagreements.
3. Run a small pilot separately. Amend the candidate protocol if needed.
4. Freeze the main-round software commit, policy, written prompt, assistance convention and stop rules before any main session. No retrospective freeze.
5. Run 6–8 genuinely fresh adults, recording all enrolments, failures, help and comprehension.
6. Fix major problems and use a separate fresh follow-up cohort when possible. Keep returning retests separate.
7. Update the seven-slide evidence story only from actual results; keep all formats aligned.

## One consolidated request for Athina

- One willing clinician (sleep/occupational/aerospace if available) and/or HCI/human-factors specialist. Supply their actual role, relevant experience, scoped comments and attribution/quotation permissions. A general clinician cannot confer aerospace approval.
- One or two pilot volunteers and then 6–8 fresh adult volunteers. No personal health information; synthetic scenario only.
- A moderator who can use the prompt and record anonymized rows. Record tested SHA, dates, assistance and unsuccessful tasks.
- Any surviving historical testing notes. Missing details stay “not recorded”; do not reconstruct outcomes from memory as if contemporaneous.

No invitation, recruitment, email or competition submission is authorized by preparation alone. Review and testing can remain explicitly pending without invented evidence. Real records and identities should be kept outside the public repository; publish consented anonymized aggregates and narrowly scoped findings only.
