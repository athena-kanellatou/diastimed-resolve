# Blank validation forms

All CSVs contain column headers only. No human observations or example people are present. Make a private copy before entering actual records; do not commit participant identities, health data or unconsented quotations to the public source repository. `examples/` contains distinctly labelled synthetic software packets only. These examples must never enter human totals.

Session/task sheets join on participant_code + session_date + commit + cohort. Use five task rows (T1–T5) for every enrolled session. A0 is independent; A1/A2/A3 are assistance. Codes and stop rules are in USABILITY_PROTOCOL_V2.md. Blank values mean not recorded, not zero. Keep pilot, main fresh and returning follow-up cohorts separate.
