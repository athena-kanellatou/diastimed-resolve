# Evaluation plan — written before benchmark results

We compare the same evidence requirements, quality gates, resource states and routine budgets. Fixed-order and greedy comparators reuse identical valid observations and stop when the same evidence requirements are met. The independent reference checks permutations without using the planner search function.

The main verification enumerates 16 evidence subsets × 4 device states × 4 budgets = 256 cases. This tests software feasibility/cost, not medical value. Additional quality and urgent tests cover stale, incompatible, future and unusable evidence and interrupted routine review.

The benchmark reports actual declared time differences, ties and infeasibility. A time advantage is specific to our illustrative catalogue and cost model; it is not an observed crew-time or clinical outcome advantage. No model sees hidden patient ground truth, because there is no patient prediction task.
