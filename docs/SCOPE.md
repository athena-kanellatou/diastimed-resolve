# Scope

DiastiMed RESOLVE helps collect the evidence specified by an explicit prototype review policy. The engine reuses compatible evidence and finds a feasible, lowest-cost sequence within a finite deterministic model. Action costs and freshness windows are engineering assumptions. The finite-model result is not a medically optimal next action.

This first working version includes guided input, resource changes, quality gates, source boundaries, local persistence, manual JSON/print export, synthetic scenarios and a three-minute PVT-inspired interaction. It excludes disease prediction, treatment, medical clearance, automated messaging and hardware integration.

Four views: Review workspace, Evidence ledger, Review brief, Research & policy. Equipment changes expose a previous/revised plan comparison. The session allowance is cumulative; original observations and separate quality amendments are included in the review export.
