# AI assistance disclosure

OpenAI ChatGPT/Codex assisted with research, concept and implementation planning, generated code/CSS, synthetic demo records, explanatory text and test design. No large language model makes decisions inside the application at runtime. No generated NASA imagery or branding is used. The project is independent and not endorsed by NASA.

The v0.3 revision also used AI assistance for storage/recovery logic, factual review summaries, evidence mapping, judging slides, submission drafts and review protocols. Deck illustrations are typography and original software material, without generated astronaut photography. No independent participant feedback is invented.

AI assistance was also used for the dashboard visual system and data-bound evidence/allocation presentation. Runtime planning remains deterministic.


The reference-led dark revision used AI assistance for layout and CSS implementation. The Earth-horizon photograph is an actual NASA image, credited in THIRD_PARTY_NOTICES.md and the interface. User-supplied design references informed the visual direction; their images and logos are not part of the app.


The globe-led mission opening used AI-assisted React, CSS and native canvas code, guided by the user-provided motion reference (https://gr.pinterest.com/pin/894386807233347718/). The reference video is not bundled. The globe uses an attributed NASA Blue Marble texture distributed with the Three.js examples; it is decorative and does not represent live mission tracking. No model runs in the review workflow.


Machine-readable code, data and presentation provenance is provided in public/development-credits.json, referenced by package.json and the HTML head. Synthetic initial scenarios are SI-assisted authored demonstrations; benchmark results are deterministically enumerated by SI-assisted code. User-entered records are not represented as SI-generated. No generative image/video model or generated audio was used; the globe and starfield are procedural visualisations created by SI-assisted code.


## Human-participant usability aggregates

The counts in docs/USABILITY.md were supplied by the team owner as human-participant testing results. SI helped format the report and calculate percentages; these counts were not generated as synthetic study data. Participant-level records and detailed error/change logs were not supplied for review.
